# Lochi Store - Handcrafted Hair Accessories Boutique Galle

Luxury satin and pure silk scrunchies, velvet hairbands, clips, and aesthetic gift boxes made in Galle, Sri Lanka.

## Features
- Handcrafted accessory catalog with stock tracking
- Cash on Delivery & Direct Bank Transfer with slip upload
- Real-time customer cart and wishlist
- Admin Command Center for managing inventory and orders
- Full-stack Vite + React + Express architecture
- Islandwide Sri Lanka delivery calculation (Free over Rs. 10,000)

## Quick Start
```bash
npm install
npm run dev
